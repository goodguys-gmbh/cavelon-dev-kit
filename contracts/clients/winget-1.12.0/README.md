# WinGet manifest schemas

Microsoft Windows Package Manager manifest schema 1.12.0, recommended by the
community repository PR template on 2026-10-14. Retrieved from the official
`aka.ms/winget-manifest.<type>.1.12.0.schema.json` URLs; redistributed under
the included MIT license. These validate generated manifests without network
access in tests. Native Windows install/uninstall checks run separately in CI.
